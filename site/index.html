Design Philosophy

Tiling when you want it.
macOS everywhere else.

Seamstress stays invisible until you reach for a tile or a seam—no tiling daemon hijacking dialogs, no virtual desktops fighting Mission Control.

Unmanaged by default

New windows open wherever macOS puts them. Seamstress never rearranges windows until you explicitly ⌥-drag them into a layout.

Relaunch layout adoption

On startup and first visit to each Space, Seamstress reconstructs existing flush-tiled layouts into live BSP trees—and restores quit apps back to their exact slots.

Native Spaces & SIP-safe

Each display and native macOS Space maintains its own 0px-gap BSP tree using read-only Space queries. System Integrity Protection stays completely enabled.

Zero idle IPC

Idle mouse movement performs zero Accessibility calls. Live seam resizing runs off the main thread on per-PID coalesced queues so sluggish apps never stall your cursor.

Interactions

Every gesture, tuned for muscle memory

Works natively with standard titlebar dragging (⌥ + drag) and macOS drag-anywhere gestures (⌃⌘ + drag).

Snapping & Splitting

  • ⌥ + Drag (empty) Center fills 100%; near an edge takes 50% and leaves an empty slot.
  • ⌥ + Drag (occupied edge) Splits that pane 50/50 along the targeted side.
  • ⌥ + Drag near T-junction Splits the entire parent split container (┬ ┴ ├ ┤) across both child panes.
  • ⌥ + Drag (center 36%) Swaps two tiled windows, or replaces a tiled pane with a floating window.
  • ⌥ + Drag onto own edge Shrinks a tiled window to that half, leaving the opposite half empty.

Seams, Intersections & Detents

  • Hover flush seam Highlights a hairline + grip pill (suppressed whenever a floating window covers it).
  • Drag seam or ┼ knob Resizes all affected panes in real time—1-axis or simultaneous 2-axis at corners.
  • Magnetic detents (⇧ free) Snaps at 50%, ⅓, ⅔, and co-linear seams, with amber clamping & Force Touch haptics at window min sizes.
  • Drag > 90% into empty Previews and collapses the empty slot on release, expanding the occupied side.
  • Double-click seam Collapses an adjacent empty slot, or resets an occupied split to 50/50.

Detaching & Undo

  • Normal Drag (no ⌥) Detaches back to saved floating size anchored under your cursor and expands neighbors. Press ⌥ within 0.45s to restore.
  • Release ⌥ mid-drag Cancels the drop preview immediately and lets the window drop as floating.
  • Esc while dragging Undoes an active window drag or seam resize while still holding the mouse button.
  • Close / Quit tiled app Auto-collapses its split. Relaunching a quit app restores its exact slot & ratio if the Space hasn't changed.

Menu Bar & Safety

  • Menu Bar Minimap Live per-display app icons (click to focus), plus Equalize and Clear.
  • ⌥-click / Right-click icon Quickly toggles Seamstress between Active and Paused.
  • Option-click protection Prevents macOS's native Option-click-to-hide from hiding and evicting unfocused tiled windows.
  • Sleep & lock resilient Pauses sanity sweeps while displays sleep or the screen is locked so layouts stay intact.
