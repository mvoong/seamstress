# Seamstress

Lightweight, mouse-driven macOS tiling window manager (`com.example.seamstress`, macOS 13+, SwiftPM).

## Module Layout

- `Sources/SeamstressCore/`: Pure Swift core with zero AppKit/AX dependencies:
  - `Geometry.swift`: CG↔NS coordinate conversion, flush integer-aligned rect splitting, cursor-anchored detach restore.
  - `LayoutTree.swift`: BSP tree with `.empty`, `.window`, and `.split` nodes (`removeWindow` leaves an empty slot; `removeWindowAndCollapse` promotes the sibling to fill vacated space).
  - `DropPlanner.swift`: Snap-drag (`⌥`-drag / `⌃⌘`-drag) zone classification with WYSIWYG same-space re-split preview simulation and distinct `.fill` / `.split` / `.splitContainer` / `.swap` / `.replace` preview kinds (split T-junctions `┬`/`┴`/`├`/`┤` split the parent container along the perpendicular axis; empty center=fill / edge=half; occupied center=swap/replace / outer=split, expanding the feasible axis's outer bands across the full cell when the perpendicular axis cannot satisfy minimum window sizes; own edge=shrink).
  - `SeamGeometry.swift`: Flush `10pt` (`±5pt`) seam hit strips, hit-testing, grab-offset tracking, `7pt` magnetic detents (`50%`, `1/3`, `2/3`) and co-linear seam alignment (`⇧` bypass), ratio clamping + `isClamped` cues, and `> 90%` collapse-to-empty detection.
  - `SpaceLayoutStore.swift`: Per-`(displayUUID, spaceID)` tree store, saved pre-tiled floating frames (with persistence snapshot/restore and full-screen adopted-window fallback), `equalizeSplits`, `restoreSeamRatios` (`Esc` cancel), per-space revision tracking + quit-and-relaunch history restore (`recordApplicationQuit`, `validQuitSnapshot`, `restoreQuitApplication`), and cross-monitor moves/swaps.
  - `LayoutHistory.swift`: Pure value types (`AppKey`, `LaunchedWindow`, `SpaceQuitSnapshot`, `AppQuitSnapshot`) for recording pre-quit Space layouts and matching relaunched windows back into unchanged Spaces.
  - `LayoutReconstructor.swift`: Pure startup/first-Space-visit BSP reconstructor from on-screen window frames (14pt edge tolerance, floating-window guardrails requiring ≥ 3 anchored edges per adopted window and disallowing nested empty-sided cuts).
  - `FrameCoalescer.swift`: Per-PID latest-frame coalescing state machine for live AX resize batches.
  - `OptionClickPolicy.swift`: Pure policy deciding when to strip `⌥` from `leftMouseDown` on unfocused windows so macOS's Option-click-to-hide shortcut doesn't hide and evict tiled windows.
- `Sources/Seamstress/`: `@MainActor`-isolated macOS menu bar runtime (`InputEventTap`, `AXWindowBridge`, `SkyLightBridge`, `DisplayObserver`, `WindowEventMonitor`, `OverlayPanel`, `DropPreviewOverlay`, `SeamHighlightOverlay`, `SeamDragController`, `WindowDragController`, `LayoutPersistence`, `WindowManager`, `MenuBarPopoverView`, `AppDelegate`, `main`). Supports custom template menu bar icon (Option-click/right-click pause toggle), hiding the menu bar icon (`seamstress.showMenuBarIcon` in `UserDefaults`; reopening presents a standalone controls window), frosted-glass drop preview with action badges, centered `┼` intersection knob, Force Touch haptics, `Esc` drag undo while holding mouse down (synthetic `leftMouseUp` termination for native window drags + seam ratio restore), and interactive app-icon minimap with Equalize/Clear actions.
- `Tests/SeamstressCoreTests/`: Headless XCTest suite covering all core invariants.
- `Resources/`: `Info.plist`, `Seamstress.entitlements`, and `generate-icon.swift`.
- `assets/demo.svg`: Self-contained CSS-animated SVG motion demo embedded in `README.md` (pure `@keyframes` on a single unified timeline; no SMIL or JavaScript; renders natively in GitHub `<img>` tags without scroll-offscreen desync).
- `Config.example.xcconfig` / `Local.xcconfig` (gitignored): Configures `PRODUCT_BUNDLE_IDENTIFIER` and `CODE_SIGN_IDENTITY` for local builds without committing personal bundle or signing identifiers.
- `scripts/install.sh`: Builds host-arch (`$(uname -m)`) Release into `build/local-install/`, resolves the binary via `swift build --show-bin-path`, renders `AppIcon.icns`, stamps `CFBundleIdentifier` from `Local.xcconfig` (`SEAMSTRESS_BUNDLE_ID` override), signs with `CODE_SIGN_IDENTITY` (`SEAMSTRESS_SIGN_ID` override, auto-detecting `Developer ID Application` or falling back to ad-hoc `-`), verifies with `codesign --verify --deep --strict`, and installs to `/Applications/Seamstress.app`.
- `scripts/release.sh`: Builds a universal (`arm64` + `x86_64`) Release bundle into `build/release/`, signs with `Developer ID Application` (`--options runtime --timestamp`), packages a signed `build/release/Seamstress-<version>.dmg` (with an `Applications` symlink), notarizes via `xcrun notarytool` using the 1Password `Development` vault item `App Store Connect Notary` (`key-id`, `issuer-id`, `AuthKey_<key-id>.p8`, overridable via `SEAMSTRESS_NOTARY_OP_ITEM` or `SEAMSTRESS_NOTARY_PROFILE`), staples and verifies with `spctl`, tags `v<version>`, pushes to the `github` remote, and uploads via `gh release create` (supports `--no-upload` and `--draft`).

## Key Implementation Invariants

- **Coordinate systems:** CoreGraphics uses top-left origin (Y downward); AppKit (`NSScreen` / `NSPanel`) uses bottom-left origin (Y upward). All conversions go through `CoordinateSpace` anchored on `DisplayObserver.primaryScreenHeight`.
- **AX write ordering:** During live resizing, shrinking windows write `kAXSizeAttribute` before `kAXPositionAttribute` (preventing Dock/screen-edge clamping on horizontal seams); growing windows write `kAXPositionAttribute` before `kAXSizeAttribute`. Cross-monitor commits use `size → position → size`.
- **Minimum window sizes:** Never latch permanent minimum sizes from immediate mid-drag AX readbacks (async/laggy apps report pre-resize sizes and freeze seams). Instead, read declared limits once via SkyLight (`SLSWindowIteratorGetConstraints`) on drag start / seam grab / adoption (`recordDeclaredMinimumSize`) and learn settled minimums with a two-sample confirmation (`240ms` + `160ms` after mouse-up, past drift correction) while reconciling downwards whenever a window is observed fitting smaller (`reconcileObservedSize`) and clearing settled overrides on detach. `DropPlanner` consults `learnedMinSizes` to clamp initial split ratios, allocate full-span outer bands to the feasible axis when the perpendicular axis cannot fit both windows, and reject geometrically impossible splits (falling back to keep-in-place / fill / swap-or-replace), `SpaceLayoutStore.collapseImpossibleEmptySplits` collapses any over-constrained empty split discovered after a drop settles, and `SeamGeometry.dragUpdate` still allows dragging toward an empty sibling if an over-constrained split arises dynamically.
- **No main-thread AX IPC:** All AX frame writes and tileability checks (`checkTileabilityAsync` / `checkTileabilityBatchAsync`) run on per-PID `.userInteractive` serial queues fronted by `PerPIDFrameCoalescer`, with O(1) cached tileability fast-paths for previously verified windows. Terminated PIDs are evicted on `didTerminateApplicationNotification`.
- **Z-order occlusion:** Seam hover and click-grab check front-to-back `CGWindowListCopyWindowInfo` so floating windows covering a seam or `┼` intersection are never intercepted.
- **SIP-safe Space & constraint queries:** `SkyLightBridge` dynamically loads read-only functions (`CGSCopyManagedDisplaySpaces`, `CGSSetConnectionProperty` for `SetsCursorInBackground`, and `SLSWindowQueryWindows`/`SLSWindowIteratorGetConstraints`) via `dlopen`/`dlsym`.
- **Sleep / screen-lock resilience:** `DisplayObserver.isSessionInactive` combines sleep/wake/lock notifications with live `CGSessionCopyCurrentDictionary` (`CGSSessionScreenIsLocked`) and `CGDisplayIsAsleep` checks. Both `runSanitySweep()` (plus a 2.5s post-wake grace window) and `adoptExistingLayoutsIfNeeded()` pause while the session is inactive so dark displays or lock screens never evict tiled layouts or permanently mark unprobed Spaces.
- **`Ctrl+Cmd` hold-to-drag lift pulse:** Holding `⌃⌘` + mouse-down before moving triggers macOS's `NSWindowShouldDragOnGesture` visual grab animation, which transiently changes `CGWindowBounds` width/height. Manual edge-resize detection in `WindowDragController` must only trigger when the press started near a window border (`CGRect.isPointNearEdge`) without `⌃⌘`, so transient size pulses never misclassify a drag as a resize.
- **Option-click unfocused-window protection:** Native macOS hides the previously active app on `⌥` + `leftMouseDown` in another app's window, which would fire `didHideApplicationNotification` and evict focused tiled windows when starting an `⌥`-drag or Option-clicking an unfocused window. `InputEventTap` tracks the frontmost PID from `WindowEventMonitor` under its lock (never touching `NSWorkspace.shared` from the tap thread), checks `OptionClickPolicy` synchronously on `leftMouseDown`, and strips `.maskAlternate` (plus device-dependent left/right Option bits `0x20`/`0x40`) before passing the event to macOS whenever Option (without `⌘`/`⌃`) clicks an unfocused app and either the clicked window or the frontmost app is tiled; Seamstress itself still records `snapModifierDown` from the original flags.
- **Diagnostics:** Lightweight `os.Logger` using `Bundle.main.bundleIdentifier ?? "com.example.seamstress"` as its subsystem (e.g. `log stream --predicate 'process == "Seamstress"'` or match your `Local.xcconfig` `PRODUCT_BUNDLE_IDENTIFIER`). Zero logging on hot `mouseMoved` / per-frame `mouseDragged` paths.

## Build, Test & Verify

```bash
swift test
bash -n scripts/install.sh
./scripts/install.sh
```

Unit tests verify pure layout, drop planning, seam geometry, and coalescing logic; live window dragging, real-time resizing, and multi-Space behavior require manual verification in `/Applications/Seamstress.app` launched via `/usr/bin/open` with Accessibility granted.
